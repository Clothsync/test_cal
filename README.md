# Cloth.sync Cost Calculator

Professional China → India garment cost calculator.

## Calculation

Product Cost:

Garment Price (RMB) × RMB → INR Rate

Cargo Cost:

Weight (Gram) ÷ 1000 × Cargo Rate / KG

Final Cost:

Product Cost + Cargo Cost

## Example

RMB Rate = ₹14
Cargo Rate = ₹400/KG
Garment Price = ¥50
Weight = 350g

Product Cost = ₹700

Cargo Cost = 350 ÷ 1000 × ₹400
           = ₹140

Final Cost = ₹840 / Piece

## Run

Install dependencies:

npm install

Start development:

npm run dev

Then open:

http://localhost:3000

## Deploy Online

Push the project to GitHub.

Then import the GitHub repository into Vercel.

No database is required for this MVP.
